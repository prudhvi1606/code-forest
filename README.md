# 🌲 Code Forest

Code Forest is a VS Code extension that visualizes each coding session as a growing tree.

## How it works
- One tree per VS Code session
- Growth based only on session duration
- Trees are saved when the session ends
- A forest view shows your coding history

## Features
- 🌱 Automatic tree growth
- ⏱ Progress ring
- 🌞 Day / 🌙 Night cycle
- 🌧 Rain / ❄ Snow effects
- 🏠 Forest view
- 📸 Export forest (if added)

## Privacy
Code Forest does not track files, languages, or typing.

## Usage
- Open VS Code → tree grows automatically
- Click 🏠 in sidebar to open forest
